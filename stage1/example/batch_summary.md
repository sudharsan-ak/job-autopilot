# Batch Stage 1 | Synthetic Example

Three synthetic jobs were evaluated: one APPLY, one BORDERLINE, and one SKIP. Two jobs were selected for the Stage 2 application queue.

## Archive contents

- `jobs_manifest.json`: machine-readable Stage 1 handoff consumed by Stage 2.
- `selected_jobs.md`: human-readable selected-role index.
- `suggest_changes_pending.md`: illustrative upstream tailoring artifact, ignored by Stage 2.
- `resumes/`: location for job-specific PDF and TeX outputs in a real private batch.

This folder contains no real applicant data, resumes, employers, or active job postings. The referenced resume files are deliberately omitted, so Stage 2 will demonstrate its configured default-resume fallback.

No applications were submitted.
